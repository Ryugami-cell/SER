# 🐾 SER Petshop

Site institucional do **SER Petshop** — desenvolvido com HTML, CSS e JavaScript puro (sem frameworks).

## ✨ Funcionalidades

- Página única (Single Page) com navegação suave entre seções
- Menu responsivo com hambúrguer para mobile
- Seção de serviços (Banho & Tosa, Veterinário, Hotel, Estética)
- Seção de produtos em destaque
- Seção "Sobre" com estatísticas
- Formulário de contato com validação
- Animações de entrada com Intersection Observer
- Layout totalmente responsivo (mobile-first)

## 🗂️ Estrutura

```
SER/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── images/         # Coloque imagens aqui
└── README.md
```

## 🚀 Como usar

Basta abrir o arquivo `index.html` no navegador. Não requer servidor ou instalação.

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3 (variáveis, grid, flexbox, animações)
- JavaScript (ES6+, Intersection Observer API)
- Font Awesome 6 (ícones via CDN)

## 📱 Compatibilidade

Compatível com todos os navegadores modernos (Chrome, Firefox, Edge, Safari).
